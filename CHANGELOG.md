# Изменения FileLens

## 1.1.0

- Добавлено окно «Параметры» с добавлением и удалением пункта «Проверить, кто держит файл» в контекстном меню Проводника для текущего пользователя.
- Выбор пункта сразу запускает проверку выбранного файла; в Windows 11 пункт находится в «Показать дополнительные параметры».
- Повторный запуск передаёт файл в существующее окно FileLens и восстанавливает его, если оно свёрнуто.
- Выбор нового файла во время проверки отменяет предыдущую проверку и запускает новую.
- Добавлены параметры `--check-file`, `--register-context-menu` и `--unregister-context-menu`.
- Согласован перезапуск от администратора с передачей единственного окна; закрытие окна сразу прекращает его текущий процесс проверки.
- Добавлены проверки регистрации меню, запуска через Windows Shell, обмена между экземплярами, восстановления окна и перезапуска после закрытия или аварийного завершения.

Программа остаётся Portable. Регистрация меню необязательна и привязана к текущему расположению EXE.

## 1.0.2

Первый публичный выпуск для Windows x64.

- Русский тёмный интерфейс с вводом пути, выбором файла и перетаскиванием из Проводника.
- Поиск процессов, использующих файл: открытые файлы, Restart Manager и загруженные модули EXE / DLL.
- Таблица нескольких владельцев с PID, описаниями и путями к программам; сведения о службах, когда их передаёт Windows.
- Проверка доступа для удаления и атрибута «Только чтение» без удаления выбранного файла.
- Кнопки «Расположение EXE» и «Копировать путь» для выделенной строки; копирование полного отчёта.
- Очистка лишних кавычек и пробелов по краям пути, включая формат Far Manager.
- Запуск от администратора, отмена проверки и ограничение её времени.
- Переносимый EXE со встроенной средой .NET.

Проверки выпуска: 43 основных сценария и 2 дополнительных сценария с 32-битными процессами. Проверено обнаружение двух разных программ, одновременно удерживающих файл, и копирование пути выбранной строки.
